## Как пользоваться заготовками

- Все упражнения из **ДЗ №2** подготовлены в `01-basics/`: 5 групп по 5 задач.
- В Java-файлах есть только название/описание задачи, класс и пустой `main` с TODO. **Решений нет.**
- Для Basic ДЗ №2 достаточно выполнить **по одной задаче из первых четырёх групп**; пятая группа про ООП — на разогрев к следующей теме.
- Для Advanced ДЗ №2 — все 25 задач, включая задачи на классы, если следовать формулировке «прорешать все задачки».
- Папки `02-oop/` и `03-data-structures/` содержат заготовки следующих ДЗ: **10** и **16** задач соответственно.
- `04-abstraction-design/` и следующие разделы зарезервированы для дальнейшей работы с интенсивом.

### Как запустить отдельную задачу

Открой файл в IntelliJ IDEA и запусти его `main` после написания решения. Можно и через терминал из папки с задачей:

```bash
javac Task01_SumAndDifference.java
java Task01_SumAndDifference
```

Здесь **нет `package`**, Maven или Gradle: это простая тренировочная структура. Названия каталогов с дефисами — не Java-пакеты.
Для задач, где нужно несколько классов (например, `Employee` и `Manager`), создавай дополнительные `.java` файлы рядом с файлом задания или оформляй вспомогательные классы так, как тебе удобно.
